# User Stories

## Story Model
Format: *As a [persona], I want [capability], so that [outcome].*  
Priority scale: **P0** (must-have), **P1** (high), **P2** (important but deferrable).

## Story Backlog (V1)

### Onboarding and Consent
- **US-001 (P0)**  
  As a new user, I want to sign in with Google so that I can access the product quickly.  
  **Links:** Personas P-01..P-05 | Requirements FR-01, BR-02.

- **US-002 (P0)**  
  As a privacy-conscious user, I want clear Gmail permission messaging so that I understand what data is accessed and why.  
  **Links:** Personas P-01, P-02, P-05 | Requirements FR-02, BR-03, NFR-05.

### Email Detection and Extraction
- **US-003 (P0)**  
  As a busy professional, I want event-related emails to be detected automatically so that I do not miss key commitments.  
  **Links:** Persona P-01 | Requirements FR-03, BR-01.

- **US-004 (P0)**  
  As a parent, I want school and family event emails to be recognized so that household commitments stay on track.  
  **Links:** Persona P-02 | Requirements FR-03, BR-01.

- **US-005 (P1)**  
  As a student, I want title/date/time/location extracted from notices so that reminders are actionable.  
  **Links:** Persona P-03 | Requirements FR-04, NFR-06.

### Event and Reminder Workflow
- **US-006 (P0)**  
  As a user, I want detected events saved automatically so that reminders can be generated without manual entry.  
  **Links:** Personas P-01, P-02, P-05 | Requirements FR-05.

- **US-007 (P0)**  
  As a user, I want default reminders scheduled at useful intervals so that I receive adequate lead time.  
  **Links:** Persona P-03 | Requirements FR-06.

- **US-008 (P0)**  
  As a user, I want WhatsApp reminders so that alerts appear in a channel I check frequently.  
  **Links:** Personas P-01, P-02, P-04, P-05 | Requirements FR-07, BR-04.

- **US-009 (P1)**  
  As a user, I want optional SMS reminders so that I can choose a secondary channel if needed.  
  **Links:** Persona P-03 | Requirements FR-08, FR-10.

- **US-010 (P0)**  
  As a user, I want duplicate events and reminders prevented so that I am not spammed or confused.  
  **Links:** Personas P-02, P-04 | Requirements FR-09, NFR-01.

### Preferences, Integration, and Operability
- **US-011 (P1)**  
  As a user, I want to manage my reminder channel preferences so that notifications match my routine.  
  **Links:** Personas P-04, P-05 | Requirements FR-10.

- **US-012 (P2)**  
  As a user, I want optional Google Calendar sync so that my event ecosystem remains consistent.  
  **Links:** Personas P-01, P-05 | Requirements FR-11.

- **US-013 (P1)**  
  As an operations stakeholder, I want workflow status visibility so that failures can be detected and resolved quickly.  
  **Links:** Stakeholder Operations | Requirements FR-12, NFR-07.

## Prioritization Notes
- P0 stories define the minimum viable product and release gate.
- P1 stories are strongly recommended for pilot quality and operational confidence.
- P2 stories are value-add and may be deferred if required for schedule control.
