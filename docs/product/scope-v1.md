# Scope Definition: MVP (V1)

## In Scope (MVP)
- Gmail integration for user-authorized email processing.
- Email event extraction for event-related messages.
- Event creation from extracted title, date, time, and optional location.
- WhatsApp reminder delivery.
- Default reminder timings (4 hours, 1 hour, 15 minutes before events).
- Optional SMS reminders.
- Optional Google Calendar sync.

## Out of Scope
- Advanced AI email interpretation beyond core event extraction.
- Recurring events and recurring reminder rules.
- Enterprise features (admin controls, organization-level workflows).
- Team collaboration and shared scheduling workflows.
- Non-Gmail email providers.
- Full automation workflows beyond event-to-reminder conversion.

## Future Versions
- Custom reminder rules and user-defined reminder timing profiles.
- Multi-channel notification expansion.
- AI assistant capabilities for proactive commitment management.
- Additional email provider support.
