# User Stories

## Account Setup
- As a new user, I want to sign in with my Google account so that I can start using the assistant quickly.
- As a privacy-conscious user, I want clear permission steps when connecting Gmail so that I understand what access I am granting.
- As a new user, I want a simple onboarding flow so that I can activate reminders without technical effort.

## Email Processing
- As a busy professional, I want my appointment emails to be automatically recognized so that I do not miss key commitments.
- As a parent, I want school event emails to be detected so that I can stay ahead of family schedules.
- As a student, I want exam and class-related emails to be identified so that important academic events are not overlooked.

## Event Creation
- As a user, I want event title, date, and time to be captured from relevant emails so that I do not need manual entry.
- As a user, I want event location to be captured when available so that reminders are more useful.
- As a user, I want detected events to appear in my event list so that I can trust what will trigger reminders.

## Reminder Delivery
- As a user, I want reminders to be scheduled automatically before each event so that I receive advance notice without setup work.
- As a user, I want WhatsApp reminders so that I receive notifications in a channel I check frequently.
- As a user who prefers text messages, I want optional SMS reminders so that I can choose my preferred notification channel.
- As a user, I want duplicate reminders avoided so that I am not spammed with repeated alerts.

## Settings
- As a user, I want to enable or disable optional SMS reminders so that notification behavior matches my preferences.
- As a user, I want to optionally sync events to Google Calendar so that my reminders and calendar stay aligned.
- As a user, I want to manage basic reminder preferences so that the product fits my routine.
