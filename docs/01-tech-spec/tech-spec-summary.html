Technical Specification Summary (MVP-Aligned)

Markdown source: tech-overview.md, backend-spec.md, integration-spec.md, and diagrams under diagrams/.

MVP Scope

  • Gmail ingestion and event detection/extraction
  • Persistence and duplicate prevention
  • Reminder schedule generation (4h / 1h / 15m)
  • Google Calendar sync as committed MVP integration (FR-09)

Post-MVP Scope

  • WhatsApp reminders (FR-07)
  • SMS reminders (FR-08)

Reliability and Failure Handling

  • Calendar sync trigger is after successful persistence + dedupe pass.
  • Retry policy: 5 attempts with exponential backoff (5s, 10s, 30s, 60s, 120s).
  • Timeout: 10s per Google Calendar call.
  • Terminal failures are logged with reason code and persisted state.
