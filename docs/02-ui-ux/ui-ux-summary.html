Executive Summary & MVP Boundaries

  • UI/UX is centered on Gmail ingestion, extraction confidence review, scheduling, duplicate prevention, and Google Calendar sync confirmation/recovery.
  • MVP interaction surfaces include Google integrations only (OAuth, Gmail, Calendar).
  • WhatsApp and SMS are explicitly post-MVP roadmap items and must not appear as active controls.
  • Primary outcomes: fast onboarding, low-friction event confirmation, explicit state messaging, and auditable failure/retry paths.
MVP guardrail: Future channels may appear only as disabled/non-interactive roadmap labels with clear “Post-MVP” annotation.

Wireframe Coverage Summary

S01-S02 Onboarding

S01 provides trust-first OAuth entry. S02 captures timezone/reminder defaults and calendar sync test/enablement with sticky actions and validation/error feedback.

S03-S05 Core Operations

Dashboard queue + events list triage into event detail where confidence, schedule preview, sync state, and confirm/dismiss actions are clearly partitioned.

S06-S08 Configuration + Recovery

Preferences capture defaults and retry policy; Integrations focuses on Google OAuth/Gmail/Calendar health; Diagnostics supports timeline investigation and sync retries.

S09 Account Controls

Session and profile controls remain separate from reminder operations, preserving safety for account-level actions.

Wireframes include desktop/tablet/mobile behaviors, explicit interaction zones, and state variants (loading, empty, error, success, permission) per screen.

Assumptions, Gaps, Open Questions

Assumptions

  • Single-user workspace per authenticated account for MVP.
  • Google integrations are the only active provider surfaces in MVP.
  • Support triage occurs primarily through Activity & Diagnostics in product UI.

Known Constraints

  • Flow and screen IDs are canonical and stable across all UI/UX artifacts.
  • Post-MVP channels remain non-interactive in MVP visual states.
  • HTML remains derivative; markdown is authoritative.

Open Questions

  • No new unresolved questions were added in this UI/UX update set.
  • Future-phase channel expansion (WhatsApp/SMS) should be revisited after MVP reliability milestones.
